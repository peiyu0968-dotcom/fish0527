# 畫面設計結果

這份文件整理 `/design` 做出的畫面設計，供階段一實作前端（`/frontend-design`）時使用。
流程與功能規則以 `docs/architecture.md` 為準，本文件只記錄「畫面長什麼樣子」。

- 設計稿（畫布）：https://claude.ai/artifact/Hrjvh1pQZpfUCAYKLfM4Eg（需登入 peiyu0968@gmail.com 才能開）
- 風格：**活潑多彩**。暖白底、紫色主色、黃色主按鈕、粗邊框加硬陰影（像貼紙），每個人有專屬顏色。手機優先，同時有電腦版。
- 畫布上所有畫面的假資料（小明、阿德、Mia、小美、大雄、波波）和圖片示意圖都只是示範，不是正式內容。

> 設計稿是靜態示意，沒有實際互動。下面「要實作的行為」一節是補充設計稿看不出來的部分。

- 設計稿裡是手動指定顏色。**實作時要依代號算出固定的組別**（例如把代號轉成數字再除以 6 取餘數），這樣同一個代號在每個人的畫面上永遠同色。
- 自己固定用第 1 組（紫），自己的訊息氣泡用 `--mine`，字為白色。
- 文字與底色的對比已以 4.5:1 為目標挑選，改色時請維持。

### 1.3 字型與大小

- 字型：**Noto Sans TC**（Google Fonts），字重 400／500／700／900。後備字型 `system-ui, sans-serif`。
- 頁面大標題 32px／900；聊天室標題 20px／900；訊息內文 15px／1.5 行高；代號 13px／900；時間與次要說明 11–13px；輸入框 16px（避免 iPhone 自動放大）。

### 1.5 圖示

全部是行內 SVG 線條圖示（stroke 2–3px、圓角線頭），沒有用 emoji。用到的圖示：聊天泡泡（標誌）、月亮／太陽（主題切換）、登出、向下箭頭、迴紋針、向上箭頭（送出）、文件、下載、鉛筆、垃圾桶、旗子（檢舉）、斜線眼睛（隱藏）、叉叉、勾勾、驚嘆號圓圈、時鐘圓圈、載入轉圈、斷線 Wi-Fi。

## 2. 畫面與元素

尺寸：手機 390×844；電腦 1280×800（內容欄寬最多 760px，置中，兩側各有一條細線）。

| 主題切換 | 右上角 44px 圓形按鈕，淺色時顯示月亮、深色時顯示太陽 |

| 代號輸入框 | 標籤「你的代號」，右上角字數計數 `n/12`，52px 高 |

| 狀態 | 畫面 |

| 圖片附件 | 224px 寬的卡片，上方圖片 128px 高，下方一行「檔名＋大小」；整張是按鈕，點了開放大檢視 |

| 已編輯 | 自己訊息下方小字「已編輯」＋時間 |

**編輯狀態**：該則自己的訊息換成白底紫框的小面板，標籤「編輯訊息」，一個輸入框，右下「取消」（白底）、「儲存」（黃底）。

**空狀態**：置中的兩個重疊圓角泡泡插畫，標題「還沒有人說話」，下方「當第一個打招呼的人吧！在下面輸入訊息，按送出就能開始。」

**載入中**：上方轉圈＋「載入歷史訊息中…」，下面是灰色骨架（頭像圈與氣泡形狀，有左有右）。

**正在輸入**：輸入區上方一行，22px 小頭像＋「小美 正在輸入」＋三個漸層透明度的小圓點。多人同時輸入時文字改為「數人正在輸入…」（設計稿只畫了一人的情況）。

**檢舉提示**：檢舉後，輸入區上方浮出深色膠囊 toast：勾勾＋「已收到檢舉，謝謝」（幾秒後消失）。

**輸入區**

| 元素 | 說明 |
|---|---|
| 附件按鈕 | 48px 圓形，迴紋針圖示，`aria-label`「附加圖片或檔案」 |
| 文字輸入框 | 48px 高膠囊，placeholder「輸入訊息…」 |
| 送出按鈕 | 48px 圓形黃底、向上箭頭。輸入框空白且無附件時停用（灰色）|
| 電腦版提示 | 輸入框下方小字「Enter 送出 · Shift + Enter 換行」（手機版沒有）|
| 附件預覽 | 輸入框上方：縮圖、檔名與大小、「上傳中 60%」、綠色進度條、取消按鈕 |
| 檔案過大 | 附件預覽下方紅色列：「合約掃描.zip · 14 MB 超過 10 MB 上限，無法傳送」，右側移除按鈕 |
| 說話太快 | 輸入區上方紅色列：時鐘圖示＋「說話太快了，請稍等」；輸入框裡的內容保留 |
| 離線 | 輸入框停用，placeholder 改成「連線後才能傳送訊息」，送出按鈕灰色 |

> 設計稿的輸入框是單行。實作時要做成可以多行、依內容自動長高（有上限，超過就內部捲動），這樣 Shift+Enter 換行才有意義。

**線上名單（浮層）**：從「N 人在線」按鈕下方展開的卡片，寬度最多 340px，標題「目前線上」與人數，每列 44px 高：頭像、代號；自己那一列有紫色「你」標籤，且排在最上面。再按一次按鈕或點旁邊的空白收起。

**圖片放大檢視（浮層）**：全螢幕深色半透明底，左上角白框圓形「關閉」按鈕，右上角黃色「下載」膠囊，中央大圖，下方白字「檔名／大小・上傳者・時間」。有 `role="dialog"` 與 `aria-modal`。

## 4. 要實作的行為（設計稿看不出來的部分）

1. **版面**：手機是整頁填滿；電腦是置中欄寬 760px。中間的訊息列表是唯一會捲動的區域，頂部列與輸入區固定。
2. **虛擬鍵盤**：手機彈出鍵盤時輸入區要跟著上移，不被遮住。
3. **自動捲動**：人在最底下時新訊息自動捲到底；不在最底下時不動，顯示「有 N 則新訊息 ↓」，點了跳到最新並隱藏。往上捲到頂端時載入更早的 50 則。
4. **訊息操作**：設計稿為了展示，把「編輯／刪除／檢舉」直接顯示。實作時改為：電腦滑鼠移上去浮現，手機點一下訊息展開。兩者都要能用鍵盤操作。
5. **頭像顏色**：依代號算出固定組別（見 1.2）。
6. **主題**：第一次依系統設定決定，手動切換後記在瀏覽器裡；切換時整頁變色，不閃白。
7. **代號輸入**：即時驗證，字數計數以「字」計（不是位元組）。
8. **圖片**：用固定大小縮圖，保持比例裁切顯示；點擊開放大檢視，按 Esc 或點背景關閉。
9. **動畫**：預設保持克制（按鈕按下時下沉陰影、浮層淡入）。遵守 `prefers-reduced-motion`，使用者設定減少動態時要關閉動畫。
10. **無障礙**：所有圖示按鈕都有 `aria-label`；新訊息與連線狀態用 `aria-live` 提示；表單用真正的 `<label>`；焦點樣式見 1.4。
